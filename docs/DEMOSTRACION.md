# Demostración individual: máximo 15 minutos

Autora: Marli Xiomara Vásquez Pérez.

| Minutos | Demostración |
|---|---|
| 0–2 | Objetivo, arquitectura y ayuda de consola |
| 2–5 | round-robin.txt: q=3, secuencia A-B-C-A-B y espera promedio=6 |
| 5–7 | memoria.txt: Out of Memory y recuperación de RAM |
| 7–10 | semaforo.txt: bloqueo de B, rechazo de escritura y resultado=2 |
| 10–13 | deadlock.txt: ciclo A-B-A, abortar A, finalizar B |
| 13–15 | Parámetros aleatorios del docente y conclusiones |

Cada guion debe abrirse en una instancia nueva; en sesión interactiva ajusta los PID según tus creaciones previas. Preparar respuestas sobre listo/bloqueado, espera/retorno, first-fit/fragmentación, wait/signal y las condiciones de deadlock.

El enunciado describe presentación grupal; esta entrega se prepara individual por instrucción de la autora. Confirma la modalidad con el docente.
